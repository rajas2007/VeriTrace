# Contributing to VeriTrace

Welcome to the **VeriTrace** project!

Please see our official contribution guidelines and workflow documentation:

* **Contribution Guidelines:** [`.github/CONTRIBUTING.md`](.github/CONTRIBUTING.md)
* **Team Development & Git Workflow Guide:** [`dev/26_TEAM_DEVELOPMENT_AND_GITHUB_WORKFLOW.md`](dev/26_TEAM_DEVELOPMENT_AND_GITHUB_WORKFLOW.md)
* **Milestone 1 Shared Contracts:** [`dev/27_MILESTONE_1_SHARED_CONTRACTS.md`](dev/27_MILESTONE_1_SHARED_CONTRACTS.md)

All pull requests must follow the layered monolith architecture boundaries, pass automated pre-commit checks (`ruff`, `mypy`, `pytest`, `check_architecture.py`), and target the `develop` branch.
